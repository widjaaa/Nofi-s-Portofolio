# Nofi Ardiman Widjaya — Portfolio

A modern, responsive personal portfolio website showcasing my work in web development, graphic design, and multimedia.

🌐 **Live Site**: [nofi-s-portofolio.vercel.app](https://nofi-s-portofolio.vercel.app/)

## ✨ Features

- **Responsive Design** — Optimized for all screen sizes
- **Dark/Light Mode** — Theme toggle with system preference detection
- **Smooth Animations** — Powered by Framer Motion
- **Interactive Gallery** — Horizontal carousel with full-screen image viewer
- **Contact Form** — WhatsApp integration for quick communication
- **SEO Optimized** — Meta tags, semantic HTML, and Open Graph support

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| [React 19](https://react.dev) | UI Framework |
| [Vite](https://vite.dev) | Build Tool |
| [Tailwind CSS 3](https://tailwindcss.com) | Utility-first CSS |
| [Framer Motion](https://www.framer.com/motion/) | Animations |
| [Lucide React](https://lucide.dev) | Icon System |
| [React Icons](https://react-icons.github.io/react-icons/) | Social & Brand Icons |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/widjaaa/Nofi-s-Portofolio.git

# Navigate to project directory
cd Nofi-s-Portofolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```

## 📁 Project Structure

```
src/
├── components/     # React components (Navbar, Hero, Projects, etc.)
├── data/           # Static data (projects, activities, certificates)
├── utils/          # Utility functions (animation variants)
├── App.jsx         # Root component
├── App.css         # Component-specific styles
├── index.css       # Global styles & Tailwind directives
└── main.jsx        # Entry point
```
